Football Finder Builds

A personal build-delivery service for the Football Finder Android app.

Privacy notice · Contact the developer

What this service does

Football Finder Builds delivers verified Android installation files (APKs), matching source archives, build information and checksums from the developer’s GitHub Actions workflow to the developer’s Google Drive.

Google authorisation connects the build-delivery service to the authorised Drive account. The service uses the limited drive.file permission to create and verify delivery files.

Privacy notice

Updated 7 October 2026

This notice covers Football Finder Builds and this information website. It describes the Google Drive delivery integration, rather than the Android app’s other features.

Google Drive data and purpose

The integration uploads build files and reads the metadata needed to verify delivery, including file names, identifiers, destination, file sizes and checksums. These data are used to deliver and check the developer’s builds. The requested Drive permission is limited to files created by or explicitly made available to this integration.

Credentials and service providers

Google OAuth credentials are held as a GitHub Actions repository secret and used by the delivery workflow to obtain access tokens. They are not included in the APK, source archive or this public website. GitHub operates the build workflow and Google stores delivered files in the authorised account. Build logs and link reports can contain delivery filenames, identifiers and verification metadata.

Retention and control

Delivered files remain in Google Drive until the account owner removes them. GitHub workflow logs and artifacts follow the repository’s retention settings. The account owner can withdraw access through the Google Account third-party connections settings and remove the delivery credentials from GitHub. Revoking access stops future uploads; it does not automatically delete existing files.

This website

This static information site includes no forms, advertising or analytics scripts. Its hosting provider, GitHub Pages, may process request information to operate and secure hosting. See GitHub’s privacy statement.
